# YD60MQ

![YD60MQ PCB](https://imgur.com/sG0cOrO.jpeg)

Customizable 60% PCB by [YMDK](https://ali.click/ow26n12).

* Keyboard Maintainer: QMK Community
* Hardware Supported: YD60MQ PCB
* Hardware Availability: [YMDK on AliExpress](https://ali.click/ow26n12)

Make example for this keyboard (after setting up your build environment):

```sh
make ymdk/yd60mq:default
```

The keyboard uses a DFU bootloader. To make a keymap and use dfu to flash it:

```sh
make ymdk/yd60mq:default:flash        # builds and flashes the 12 LED variant
```

See the [build environment setup](https://docs.qmk.fm/#/getting_started_build_tools) and the [make instructions](https://docs.qmk.fm/#/getting_started_make_guide) for more information. Brand new to QMK? Start with our [Complete Newbs Guide](https://docs.qmk.fm/#/newbs).
